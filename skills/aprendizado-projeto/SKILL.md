# Aprendizado de projeto

Leia `~/.config/opencode/projects/index.md` e siga os procedimentos de identificação, registro de aprendizado ou associação de projetos, conforme o pedido. Use o contexto e o pedido do usuário para determinar o que registrar ou associar; se não estiver claro, pergunte. O índice é a fonte de verdade para cadastro, segurança, associações e atualização dos perfis.
